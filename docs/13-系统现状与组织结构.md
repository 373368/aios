> 定位：AI-OS 当前阶段的**实际文件/能力/工作流/规范盘点**。每项标注「可编程化程度」（已原语化 / CLI 脚本 / LLM 判断点），是「从 skill 内嵌 → 确定性原语」演进的真实基线。

## 1. 总体架构（OS 定性落地 · 四层 + 控制面）

```
L1 主控层（opencode agents，判断点自治，直接持有原语运行元件）
  └─ 会话纪律（AGENTS.md）+ 任务派发规范 + 记忆沉淀（memory/）
        ▼ 编排
[控制面] loopx：goal / todo / quota / gate / evidence / peer（跨天长任务）
        ▼ 驱动
[工作流层]（声明式 YAML 编排 + 锁/日志/退出码，wfengine.py 执行）
  ├─ archive-daily / digest-daily / track-daily / wf-selfcheck（✅ 声明式已验证）
  ├─ wf-test-judge（测试用）
  └─ wfctl 统一接口：list / catalog / status / render / trigger / run-agent
        ▼ 调用
[原语层]（= 工具统一体，scripts/ + tasks/ + MCP + stdlib）
  ├─ primitives.py（写操作 5 原语）
  ├─ sys_classify_sdk.py（分类固化 4 原语）
  └─ 独立脚本原语：scan_new / build_index / search_index / chunk_sessions / embedders / fetch_*
        ▼
资源层
  ├─ vault（05-知识 622 页 + 01-记忆 18 页 + 06-系统 8 页 + 03-日志）
  ├─ index（qwen 646 页，fd_bm25 v1 引擎，2026-09-06 重建）
  └─ export / chunks（工程中间态）

[L4 OS 层] AiosShell（C# WebView2，单口网关 8799）+ React 工作台 + 星空图（force-graph）
  ├─ 能力面板：工作流/Agents 两页签 =「能力卡 → 详情页」两态（catalog 驱动；元数据表单就地运行；invokes/invoked_by 互跳；机读任务 ui_hidden 不上表面板；新建身份支持 AI 填充 agents-suggest，2026-09-17）
  └─ Chat 顶栏：opencode(4400) / OpenScience(4401) / loopx chat(8767)
```
