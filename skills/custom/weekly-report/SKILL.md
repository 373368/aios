# Weekly Report — 周期统计周报

## 目标

每 7 天汇总一次：知识沉淀量、行为记录、与长期事项的对比。产出统计笔记 + 桌面通知。

## 触发

- **计划任务**：每周日 21:55 由 Windows 计划任务触发（`opencode run "每周统计"`）
- **主动询问**：用户说"出统计 / 周报 / 统计一下" → 即时执行
- 执行前**先自动跑一次 vault-digest**（保证统计基于已沉淀状态）

## 流程

### 1. 预处理
- 执行一次 vault-digest（沉淀最新完成的项）

### 2. 数据采集
- **沉淀量**：统计 `05-知识/` 近 7 天新增/修改的笔记数（frontmatter updated 或 mtime）
- **行为记录**：读 `05-知识/行为记录/` 近 7 天条目（触发方式/耗时/读取的笔记）
- **记忆流动**：`D:\AI OS\l1-control\opencode\.opencode\memory\` 中被 `digested` 标记但今天仍在的项数（=待归档存量）
- **待办**：当前 active 待办快照（来自 memory + vault 02-任务）

### 3. 对比长期事项
- 读 `04-项目/` 与 `06-系统/` 的长期事项/目标
- 对齐：本周沉淀是否服务长期事项？标记"有进展/无进展/偏离"
- **长期待办栏在建立之前留空**（当前阶段长期待办未定义）

### 4. 生成报告
写入 `03-日志/周报-YYYY-MM-DD.md`：
```
# 周报 <日期范围>
## 本周沉淀
  - 新增知识 X 篇（列出主要主题）
  - 行为记录 Y 条（触发分布）
## 与长期事项对比
  - 待办存量 / 进展方向
  - 长期待办：<建立前留空>
## 下周建议（可选）
## COMPLETED <时间>
```

### 5. 通知 + 落盘
- 桌面通知（notifier/toast）发简短摘要（沉淀数+主要方向）
- 完整报告入 `03-日志/`

## 中断恢复

周报若被中断（未写 COMPLETED）：
- 下次触发**跳过"当天已完成的部分"**：读上次周报尾部，未 COMPLETED 则续跑而非重跑
- 数据采集按**绝对日期窗口**（近 7 天），不依赖上次跑没跑——漏跑一周不影响数据完整性
- 若连续两次未跑（计划任务关停等），恢复后一次统计窗口为"最近 7 天 + 补记漏跑期间"，标记 `catch-up: true`，不伪造数据

## 验收

- [ ] 触发后生成周报（含沉淀量/行为记录/长期对比）
- [ ] 通知发出
- [ ] catch-up 场景正确补记而非丢数据
- [ ] COMPLETED 标记使中断重跑可续
